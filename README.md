# parklegal Система генерации колонтитулов

## Какова логика работы кода

1. Цель - чтобы сгенерировать жалобу на постановления о штрафе за неправильную парковку в мск
2. Человек вбивает в форме на сайте данные: номер постановления, дату, адрес нарушения
3. Из адреса нарушения идет вычисление, в какой суд надо обратиться - код проверяет данные на сайте судов (геометрическая проекция районов судов) потом через геокодер устанавливливает координаты адреса, метчит данные и устанавливливает суд (эти данные публичные)
4. Установив данные, код должен подставить их в плейсхолдеры в вордовском документе и выдать файл

## Предварительный запуск

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Настройте переменные окружения:

   - Скопируйте пример конфигурации:

     ```bash
     cp .env.example .env
     ```

   - Откройте файл `.env` и при необходимости укажите значения для переменных. Основные переменные:
     - `DOCGEN_YANDEX_GEOCODER_API_KEY` — API-ключ Яндекс.Геокодера (обязательно для работы).
     - `DOCGEN_TTL_SECONDS` — время жизни сгенерированных файлов в секундах (по умолчанию 7200).
     - `DOCGEN_PUBLIC_BASE` — публичный URL сервиса (по умолчанию `http://localhost:8000`).
     - `DOCGEN_HOST` и `DOCGEN_PORT` — хост и порт, на которых будет запущен сервер.
     - `DOCGEN_TEMPLATES_DIR` и `DOCGEN_STORAGE_DIR` — пути к шаблонам и хранилищу документов.

4. Запустите приложение:

   - С помощью Uvicorn:

     ```bash
     uvicorn main:app --host 0.0.0.0 --port 8000 --reload
     ```

   - Или напрямую через Python:

     ```bash
     python main.py
     ```

После запуска приложение будет доступно по адресу `http://127.0.0.1:8000`.

Документация (Swagger UI) и возможность опробовать сервис доступна по пути:

- `http://адрес-запущенного-сервера/docs`
